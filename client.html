🔌 Соединение
offline
Если к ТВ подключены клавиатура и мышь напрямую — включи этот чекбокс: автоопределение Smart TV по User-Agent ненадёжно и может ошибочно посчитать ТВ мобильным тач-устройством, отключив обработку физической клавиатуры.
🎮 Управление
Каждый символ / Enter / Backspace / Delete отправляется мгновенно. Работает на ПК и телефоне.
Только ПК — press для одиночных клавиш, hotkey для комбинаций с Ctrl/Alt/Shift
⚡ Быстрые команды
🔧 Спецклавиши (F1–F12, пунктуация)
Эти кнопки шлют нажатие напрямую по тапу, в обход перехвата физической клавиатуры — работают всегда, даже если браузер резервирует клавишу за собой (актуально для F6/F7 на ПК).
🔥 Хоткеи
🖱 Средняя кнопка мыши (СКМ) всегда выполняет действия ПРАВОЙ кнопки. Действия средней кнопки отдельно не отправляются.
⚠️ Ctrl+Alt+Delete невозможно отправить программно — Windows блокирует это на уровне ОС.
